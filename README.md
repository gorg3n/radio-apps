# Учебные приложения по системам радиосвязи

Шесть автономных интерактивных веб-приложений к лекциям курса «Системы и сети подвижной радиосвязи». Каждое приложение — один HTML-файл: открывается двойным щелчком в браузере, работает без интернета, без установки и без сервера.

## Как открыть

- **Онлайн:** по ссылкам из таблицы выше.
- **Локально:** скачайте репозиторий и откройте HTML-файл нужной папки двойным щелчком.

Для демонстрации на проекторе рекомендуется полноэкранный режим браузера (F11).

## О приложениях

У каждого приложения есть свой `README.md` в папке — подробное описание «что это и как работать», вопросы для аудитории и границы модели.

Все приложения — учебные демонстраторы: модели упрощены и подобраны наглядными, для инженерных расчётов не предназначены. Числа и факты взяты из лекций курса.
